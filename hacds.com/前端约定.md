# hacds.com 官网 · 前端约定

> 这些约定来自 2026-10-28 上线时实际踩到的坑。改代码前先读一遍。

---

## 1. 所有用户可见文案必须走 i18n

站点支持 **中文 / English / Türkçe** 三语。任何用户能看到、看到的字都不能硬编码。

### HTML 里

```html
<span data-i18n="app.poolDs"></span>
```

### JS 里（动态拼接的日志、错误、按钮动作名）

```js
const t = (k, ...a) => {
  let s = (window.I18N && window.I18N.t(k)) || k;
  a.forEach((v, i) => { s = s.replace('{' + i + '}', v); });
  return s;
};

log(t('log.buildingSwap'));                       // 简单
log(t('log.mintDone', ok, fail));                 // 带占位符 {0} {1}
```

**不要**写 `log('构建兑换交易…')`。2026-10-28 上线时发现 `/app/` 里有
76 处这样的硬编码，英文和土耳其语界面全在漏中文。

### 加新 key 的规矩

三种语言**必须同时加**。检查脚本：

```bash
python - <<'PY'
import re,glob
s=open('assets/js/i18n.js',encoding='utf-8').read()
st=[m.start() for m in re.finditer(r'\n    (zh|en|tr): \{', s)]; st.append(len(s))
sets=[set(re.findall(r"'([a-zA-Z0-9_.]+)':", s[st[i]:st[i+1]])) for i in range(3)]
for i,n in enumerate(['zh','en','tr']): print(n, len(sets[i]))
print('zh-en 差:', sorted(sets[0]-sets[1]), sorted(sets[1]-sets[0]))
print('zh-tr 差:', sorted(sets[0]-sets[2]), sorted(sets[2]-sets[0]))
PY
```

当前基线：**三种语言各 244 个 key，键集完全一致。**

### 硬编码中文自检

```bash
python - <<'PY'
import re,glob
for f in sorted(glob.glob('assets/js/*.js')):
    if f.endswith('i18n.js'): continue
    s=open(f,encoding='utf-8').read(); n=0
    for i,line in enumerate(s.split('\n'),1):
        st=line.strip()
        if st.startswith(('//','*','/*')): continue
        for m in re.finditer(r"(['\"`])((?:(?!\1).)*)\1", line):
            if re.search(r'[一-鿿]', m.group(2)):
                print(f"{f}:{i}  {m.group(2)[:60]}"); n+=1
    if n: print()
PY
```

期望输出：只有 `whitepaper.js` 里的中文**文件名**（`/whitepaper/HacdsDeFi-白皮书.md`），
那是文件路径，不是文案。

## 2. 部署前必须做

**永远不要** `cd hacds.com && wrangler deploy`。
仓库根 `wrangler.jsonc` 的 `assets.directory` 指向 `hacds.com`，
wrangler 会向上找到它，把 `worker/index.js`、`README.md`、`部署指南.md`
一起当静态资源传上去 —— 实测泄漏过一次。

正确做法：

```bash
cd hacds.com
CLOUDFLARE_ACCOUNT_ID=9dfd2a5ab648b9a7b57078df932aeb48 \
  bash deploy-site/build.sh --deploy
```

脚本用**白名单**拷贝 27 个文件，并在部署前自检 `public/` 里没有敏感文件。

---

## 3. 站点 Worker 的行为

`deploy-site/worker.js` 做三件事：HTTP→HTTPS 301、www→主域 301、补安全头。

**`wrangler.jsonc` 里 `"run_worker_first": true` 不能删。**
删了之后静态资源直接命中 assets、绕过 Worker，重定向静默失效 ——
页面看着完全正常，只是不跳转，很难发现。

## 4. 本地预览的坑

```bash
cd deploy-site/.build/public
python -m http.server 8901 --bind 127.0.0.1
```

- **别重复起多个同一端口的 server** —— Windows 上后起的会失败但前一个继续服务，
  于是你改了文件、浏览器还是旧内容。用 `netstat -ano | grep :8901` 确认只有一个 PID。
- 预览完记得 kill 掉，否则 `build.sh` 会报 `Device or resource busy`。
- 本地预览走 `config.js` 的 `useLocal` 分支（请求打到 `127.0.0.1:8082`），
  本机没跑节点时控制台会有一堆 `ERR_CONNECTION_REFUSED`。**这是预期的**，
  不代表页面有问题；线上走 `api.hacds.com`。

## 5. 合约未上线时的状态

- 首页横幅必须是 `banner.testnet`（「新版合约待部署」），不能用 `banner.mainnet`。
- `/app/` 里的协议状态格会显示「—」，写操作会提示「构建服务尚未部署」，都是预期。
- `/app/` 的 HACD 存入/赎回是**故意不支持**的桩（`txbuild.js` 返回 `{ok:false}`），
  提示用户去用桌面钱包或 Android —— 因为那需要多动作交易。

合约上线后要改的地方：

1. `index.html` 的 `data-i18n="banner.testnet"` → `banner.mainnet`
2. 跑一次 §5 的功能验证清单（`部署指南.md`）
