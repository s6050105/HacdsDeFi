## 这份说明书是给谁看的

给拿到这个钱包、第一次打开、不知道该点哪里的人。

假设你不懂合约、不懂 HVM，也不需要懂。看完你应该能自己完成：装好、建钱包、

## 1. 先准备三样东西

**一台电脑**（Windows 64 位）**或一台安卓手机**。

| 平台 | 文件 | 说明 |
|---|---|---|
| PC | `HacdsDeFi-Setup-0.4.0-x64.exe` | 安装版，双击装好 |
| PC | `HacdsDeFi-0.4.0-x64.exe` | 免安装版，双击直接运行 |
| 安卓 | `HacdsDeFi-0.2.0-arm64.apk` | 需允许"安装未知来源应用" |

PC 两选一即可。手机只支持 arm64（近年所有主流机型）。

**能连上服务器。** 钱包本身不存链上数据，它要连两个服务：

| 服务 | 地址 | 干什么 |
|---|---|---|
| 节点 | `node.hacds.com` | 查余额、广播交易、读合约状态 |
| 索引器 | `indexer.hacds.com` | 借贷清算用的台账（可选） |

这两个地址已经填好了，网络通就不用改。如果要换，在顶部改。

> **只有两个服务，没有预言机了。** 旧版还有一个"给钻石出评分证书"的服务，
> 那个已经整个删除——现在合约自己读钻石基因算分，不需要任何链下环节。

## 2. 第一次打开

PC 端顶部是这样一排：

```
[节点] [索引器] [合约] [保存] [检测]     [−] 100% [+] [⟲]   [语言▾]
```

**第一件事：点「检测」。**

点完看下方日志区，应该出现 `节点 OK，高度 79xxxx`。

如果节点不通，先检查网络。**索引器不通不影响用**，只是清算页会慢一些（它会退回本地扫块）。

## 3. 建钱包（或导入已有的）

### 3.1 新用户：创建钱包

点「创建钱包」，设一个口令。

**口令至少 8 位，丢了就找不回来。** 钱包文件加密后存在本机，没有"找回"功能，
没有客服，没有后门。请写在纸上，别只存在电脑里。

创建完成后会显示你的地址（`1` 开头，约 34 位）和 12 个助记词。
**助记词抄下来，离线保存。** 它是你恢复钱包的唯一办法。

### 3.2 已有钱包：三种导入方式

| 方式 | 用在哪 |
|---|---|
| 助记词 | 从别的钱包迁过来 |
| Keystore 文件 | PC 和安卓互通，格式一样（`hacds-keystore v1`） |
| 私钥 | 有历史遗留私钥时用 |

### 3.3 管多个钱包

点「钱包管理」能看到本机所有钱包，切换、重命名、删除都在这里。

## 4. 解锁后看到什么

顶部是**七个页签**，和网页版完全一致：

```
[兑换] [流动性] [借贷] [HACD] [转账] [资金] [工具]
```

下面三张常驻卡片：

| 卡片 | 内容 |
|---|---|
| 资产总览 | HAC、HACD 颗数、hacds 余额、合约内配额 |
| 协议状态 | 池子两侧储备、参考价、借贷利用率 |
| 借贷状态 | 你的债务、抵押、健康度 |

三张都可以点右上角的 `▾` 折叠。

## 5. 三张卡怎么读

### 5.1 资产总览

| 项 | 含义 |
|---|---|
| HAC | 钱包里能直接花的 HAC |
| HACD | 你持有的钻石颗数 |
| hacds（配额） | **合约内**账面上的 hacds，还没领到链上 |
| hacds（链上） | 已经在你自己地址里的标准资产 |

**两个 hacds 相加才是你真正拥有的全部。**

### 5.2 协议状态

| 项 | 含义 |
|---|---|
| 池 HAC / 池 hacds | AMM 池子两侧的储备 |
| 参考价 | 合约用来清算估值的平滑价格 |
| 利用率 | 已借出 / 可出借，超过 50% 不能再借 |

### 5.3 借贷状态

**健康度**这一栏最重要：

| 显示 | 状态 | 会发生什么 |
|---|---|---|
| > 10000 | 安全 | 什么都不会发生 |
| = 10000 | 危险 | 正好在清算线上 |
| < 10000 | 可清算 | 任何人可以随时清算你 |
| < 9000 | 深水区 | 可以被一次清完全部债务 |

**没有宽限期。** 跌破 160% 抵押率就随时可被清算，不会提前通知你。

## 6. 每笔交易都是同一套动作

不管做什么，流程都一样：

```
填参数 → 点「生成交易」 → 看预览 → 点「广播」 → 等上链
```

**预览区会显示**：动作、字节数、手续费、签名摘要。

**广播之后的三种结果**：

| 结果 | 意思 |
|---|---|
| `ret:0` | 进了内存池，**还没上链** |
| 上链了 | 余额会变 |
| 报错 | 看日志，中文说明 |

**出块约 300 秒。** 广播成功不等于立刻生效，钱包会自动补刷几次（15/45/90/180/320 秒）。

## 7. 常见操作怎么做

### 7.1 把钻石换成 hacds（最常用）

1. 点「HACD」页签
2. 点「加载我的钻石」
3. **勾选你要存的钻石**——可以一次勾很多，最多 200 颗
4. 点「批量存入兑换」

**一次交易、一次签名，最多 200 颗。** 这是这一版最大的改动：旧版一次只能存 1 颗。

界面会显示预计铸出的 hacds 数量：**1 分 = 1 亿 hacds**。

> **注意**：存入之后你拿到的是**合约内的配额（due）**，还不是链上资产。
> 要拿到链上钱包里，看 7.2。

### 7.2 把 hacds 领到手

点「资金」页签 → 「领取 hacds」→ 填数量 → 生成 → 广播。

**这一步才把 hacds 真正转进你的地址。** 领到之后，它就是一个标准的链上资产，
可以转到任何支持 Hacash 资产的钱包或交易所。

### 7.3 充 HAC 进合约 / 提出来

「资金」页签：

| 操作 | 做什么 |
|---|---|
| 充 HAC | 钱包里的 HAC → 合约内的 HAC 积分（用来加流动性、还款） |
| 提 HAC | 合约内积分 → 钱包 |
| 充 hacds | 链上 hacds → 合约内配额（用来加流动性、抵押） |
| 领 hacds | 合约内配额 → 链上 |

**注意区分**：合约内的是"积分"，链上的是"资产"。两者不是一回事，
AMM 和借贷操作的都是**合约内**的那份。

### 7.4 在池子里换币（AMM）

「兑换」页签，两个方向：

| 操作 | 填什么 |
|---|---|
| HAC → hacds | 投入 HAC（单位 HAC） |
| hacds → HAC | 投入 hacds（单位：个） |

输入后下方会实时显示**能换到多少**和**当前池价**。

**滑点保护**：`min_out` 填你能接受的最少得到量，`0` = 不限制。
行情波动大时建议填个数，防止被别人抢跑。

### 7.5 加流动性赚手续费

「流动性」页签。

填 HAC 侧数量，**hacds 侧会自动按池内比例算出来**。这是防止你配错比例白送钱。

| 事项 | 说明 |
|---|---|
| 手续费分成 | 交易费的 **80% 给 LP**，20% 进金库 |
| 赎回费分成 | 赎回手续费的 **80% 也给 LP** |
| 无常损失 | 有。这是所有 AMM 的固有特性 |
| 信用风险 | 池里 30% 的 HAC 被借出去，最坏情况损失这 30% |

**撤池要分两步**：先「领取 LP 奖励」，再「撤出流动性」。
钱包会自动帮你拆成两笔，你点一次就行。

> 为什么要拆？单笔会撞主网 resource 桶上限（6,102 > 6,100）。
> 这是实测出来的坑，合约改不了，只能在钱包侧拆。

### 7.6 抵押借币

「借贷」页签。

1. 先「追加抵押」，抵押的是**合约内的 hacds 配额**
2. 再「借出」，最多借抵押价值的一半

**输入框下方会实时显示**：当前可借上限、这笔需要的抵押、当前抵押价值。
不用试错。

**利率是浮动的**：利用率 0% → 2%，35% → 6%，50% → 46%。

**还不上会被清算。** 没有宽限期。建议：
- 别借满（借 30%–40% 比借满从容得多）
- 健康度到 150% 附近就补仓
- 盯「借贷状态」卡里的健康度，它和链上清算用**同一个价格**

### 7.7 把币转给别人

「转账」页签，四种：

| 类型 | 说明 |
|---|---|
| 转 HAC | 链上 HAC |
| 转 hacds | 链上 hacds 资产 |
| 转 HACD | 钻石，可以一次多颗 |
| 转其它资产 | 填 serial + 数量 |

### 7.8 HACD 页：看钻石、批量操作

「HACD」页签上下两块：

**上半：存入**
- 加载我的钻石 → 勾选 → 批量存入
- 单笔最多 200 颗

**下半：赎回**
- 加载池内钻石 → 选一颗 → 赎回
- **赎回只能一次一颗**

> 为什么赎回不能批量？赎回要给每颗钻石单独算「挑钻石溢价」（高分钻石多付钱），
> 而且批量操作一旦中途失败，回滚逻辑在不可升级的合约里风险太高。
> 钱包会自动把你选的拆成多笔，你点一次即可。

## 8. 进阶功能（不看也能用）

### 8.1 只读查询

「工具」页签 → 「只读查询」。可以直接调合约的任意只读函数，看返回值。
排查问题时很有用。

### 8.2 原子交易

多个动作并进一笔交易，要么全成要么全败。协议上限 200 个动作。

### 8.3 离线签名（冷热分离）

「工具」页签 → 「离线签名」：

1. 冷端（不联网的机器）填参数、生成、签名
2. 输出二维码或文件
3. 热端（联网机器）扫码或读文件，广播

**私钥全程不触网。** Hacash 的交易没有 nonce、没有时间戳过期，
离线签好的交易放很久再广播依然有效。

### 8.4 清算 / 结算

「工具」页签 → 「清算」。列出所有可清算的地址和健康度。

清算是有钱赚的：你替别人还债，拿走「还款额 + 5%」的抵押品。
普通清算单次最多处理对方一半债务。

### 8.5 续租存储键（运维）

「工具」页签 → 「续租」。

Hacash 的合约状态要付租金，键到期会失效。**任何人都能续租，还能拿到报酬 （0.07 HAC/键）**。keeper 就是这么工作的。

普通用户可以不管——项目方的 keeper 会自动续。

## 9. ⚠ 数字怎么看（最容易出错的一节）

### 9.1 hacds 就是个数

**这一版 hacds 是 decimal 0 —— 1 就是 1 个，没有小数。**

余额、池子、抵押、输入框，看到的都是同一个数字。

```
想转 70 个 hacds → 输入框填 70
```

> **和旧版不同！** 旧版（#2000）是 decimal 8，那时输入框填的是 atoms，
> 要填 `7000000000` 才是 70 个。**这一版不要乘 1e8。**

### 9.2 HAC 也是个数

标签写「（HAC）」的地方，想充 10 个 HAC 就填 `10`。

**例外**：链上转账页的 HAC 金额要写成 `1:248` 这种格式（`1:248` = 1 HAC）。
这是 Hacash 的金额写法，照输入框默认值的样式改就行。

> `a:b` = a × 10^(b−248)。所以 `5:249` = 50 HAC，不是 5.0038。

### 9.3 对照表

| 你要操作 | 填什么单位 | 例子 |
|---|---|---|
| 加流动性 —— HAC 侧 | HAC | `1` |
| 加流动性 —— hacds 侧 | 个数 | `33183372` |
| 换币 —— 投入 HAC | HAC | `1` |
| 换币 —— 投入 hacds | 个数 | `100000000` |
| 追加抵押 | 个数 | `100000000` |
| 借出 / 还款 | HAC | `0.5` |
| 转 hacds | 个数 | `100000000` |
| 转 HAC（链上） | `值:尾数` | `1:248` |

**记住一句话**：hacds 填个数，HAC 填 HAC 个数（链上转账除外）。

### 9.4 为什么容易搞错

HAC 和 hacds 的量纲不同：

- **HAC** 链上是 zhu，1 HAC = 1e8 zhu，界面上用 HAC
- **hacds** 链上就是个数，1 = 1 个

所以 `add_liquidity(hac_amt, ds_amt)` 两个参数的单位不一样：一个是 zhu，
一个是 hacds 个数。这是最容易犯 1e8 倍错误的地方——我们自己在首注时就犯过一次。

## 10. 出问题了怎么办

### 10.1 先看日志区

所有操作的结果、失败原因都打在底部日志区。**报错是中文的**，
先说是什么问题，再给建议。

### 10.2 常见报错

| 你看到的 | 什么意思 | 怎么办 |
|---|---|---|
| 余额不足 | 合约内积分不够 | 先去「资金」页充值 |
| `resource gas limit exceeded` | 单桶 gas 超限 | 拆成多笔；**提高 gas_max 无效** |
| `compute gas limit exceeded` | 同上 | 拆成多笔 |
| `CallNotExist(51)` | 合约没这个函数 | 管理员函数已全部删除，别点了 |
| `NotFindContract` | 该地址没有合约 | 合约未部署或地址填错 |
| `StorageNotActive` | 存储键过期 | 去「工具」页续租 |
| `state changed` | 期间链上状态变了 | 重试 |
| `sandbox_per_ip_concurrency_exceeded` | 并发超限 | 等几秒重试（节点限制每 IP 2 个并发） |
| 网络错误 | 服务连不上 | 检查节点地址和网络 |

### 10.3 广播成功但余额没变

正常。出块约 300 秒。等一会儿点「刷新资产」。

### 10.4 界面字太小 / 太大

顶部 `−` / `+` 调，`⟲` 复位。

### 10.5 三张卡可以收起来

点卡片右上角的 `▾`。

## 11. 安全须知

1. **助记词和口令离线保存。** 没有找回功能，没有客服。
2. **别把全部身家放进来。** 合约不可升级，发现 bug 也改不了。
3. **金库私钥是单点。** 合约里没有提款函数，没人能拿走你的资产；
   但金库里的协议收入由项目方的冷钱包控制——这是唯一需要信任他们的地方。
4. **没有管理员。** 没有任何人能暂停合约、改参数、冻结你的账户。
   这一点可以从函数清单直接验证。
5. **官方不会主动私聊你。** 任何要你"验证钱包""发送助记词"的都是骗子。
6. **离线签名时，私钥全程不触网。** 冷端机器最好永久断网。

## 12. 一些术语的通俗解释

| 名词 | 人话 |
|---|---|
| **hacds** | 把钻石存进合约后得到的代币，1 分钻石 = 1 亿个 |
| **HAC** | Hacash 主币，就是能花的钱 |
| **HACD** | 钻石，存进合约能换 hacds |
| **due / 配额** | 合约账面上记给你的 hacds，还没领到链上 |
| **AMM** | 自动做市，一个池子，谁都能来换，价格自动调 |
| **LP** | 流动性提供者，把钱放进池子赚手续费的人 |
| **滑点** | 你的交易把价格推动了多少，大额交易滑点大 |
| **抵押率** | 抵押品价值 ÷ 债务，200% 是借款线，160% 是清算线 |
| **健康度** | 抵押率的另一种写法，10000 = 正好在清算线上 |
| **清算** | 你还不上钱，别人替你还，拿走你一部分抵押品 |
| **深水区** | 抵押率跌破 105%，可以被一次清完全部债务 |
| **hcut** | 极端坏账时的全局缩水系数，只降不升 |
| **keeper** | 自动给合约续租的人，能拿报酬，谁都能跑 |
| **参考价** | 合约用来估值的平滑价格，和现货价不一样，防操纵 |
| **原子交易** | 多个操作打包成一笔，要么全成要么全败 |
