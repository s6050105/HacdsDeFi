协议概览

hacds 是运行在 Hacash 主网上的 DeFi 协议。它把 HACD 钻石的评分转化为同质化代币 hacds，并围绕这个代币构建了兑换、做市、借贷三套金融原语。

设计目标

上一版把 hacds 做成刻在钻石上的铭文，导致代币无法拆分、无法自由流通。这一版的核心改动只有一条：把币从钻石上拿下来。

hacds 现在是标准的 Hacash 链上资产：可自由转账、可拆分、可在 AMM 里交易。钻石只作为铸造它的凭证，不再承载它。

三个组成部分

组件职责位置
合约持有全部资产与账本，执行兑换/借贷/赎回Hacash 主网 HVM
节点提供链上查询与交易广播由社区或项目方运行
索引器扫链建台账，提供借款人与 HACD 列表链下服务

新版设计已移除预言机：HACD 评分改由合约链上直读基因计算，不再依赖链下签名证书。

系统架构

整个协议只有一个合约地址，所有状态都在其中。没有管理员，没有升级入口，没有自毁函数。

职责边界

  • 合约 — 唯一的事实来源。所有余额、债务、池子状态都在链上。
  • 钱包 — 只管签名。私钥从不离开用户设备。
  • 官网 — 只构建交易体，不碰私钥，不保存任何用户数据。
  • 索引器 — 只读。合约无法枚举地址，索引器补上这个能力。

AMM 兑换

恒定乘积做市（x × y = k），费率 0.5%，从输入腿收取。

报价公式

输入 amt，扣费后 net = amt × (1 − 0.005)
输出 = pool_out × net / (pool_in + net)

滑点保护

所有兑换与流动性操作都带 deadline（块高）和 min_out / min_share 参数。任一不满足则整笔回滚，防止被抢跑。

抵押借贷

用户把 hacds 划为抵押品，借出 HAC。

关键参数

参数值含义
借款线200%债务 ≤ 抵押价值 / 2（50% LTV）
清算线160%抵押率跌破 160% 可被清算
价格缓冲20%从满借到清算的下跌空间
清算奖励5%按清算人付款额计，非债务比例
close factor50%单次最多清算一半债务

利率模型

U ≤ 35%:  rate = 2% + 4% × U / 35%
U > 35%:  rate = 6% + 40% × (U − 35%) / 15%

U = 利用率 = 总债务 / HAC 提供者总量
U=0 → 2%   U=35% → 6%   U=50% → 46%

清算

抵押率跌破 160% 后，任何人可发起清算。清算人支付真 HAC，按「付款额 + 5% 奖励」的价值获得对应抵押品。

注意：抵押品交割按付款额计算，不按债务比例。按债务比例会在 160% 抵押率下让清算人拿走借款人几乎全部权益。

HACD 铸造与赎回

铸造（存入 HACD）

存入 1 颗 HACD，按评分铸造等量的 hacds。不打折：1 分 = 1 hacds。

score = score_of(diamond_name)
mint  = score × SCORE_SCALE     // 100%，无折扣

赎回（取出 HACD）

支付 hacds 换回一颗 HACD。基础手续费 0.5%；若该钻石评分高于池内均分，额外收取「挑钻石溢价」。

avg = 池内总分数 / 颗数
premium = min(30%, (score − avg) / avg)
fee = 0.5% + premium

溢价上限 30%，防止有人反复从池子里挑走高分钻石、把低分货留给其他持有人。

评分机制

HACD 评分采用 HIP-5 的五维算法：形状、样式、颜色、命名、编号。

维度说明取值依赖
形状Square / Heart / Circle 等 8 种visual_gene[0..2]
样式仅 Common 形状参与visual_gene[2..18]
颜色名字首字母 + 明暗加成visual_gene + name
命名6 字母的重复/对称加成diamond name
编号顺子、对称数字加成diamond number
链上直读，无预言机

新版合约通过 HVM 内置直接读取钻石基因并在链上算分，不再依赖链下签名证书。这消除了「谁持有预言机私钥谁就能增发」的风险。

风险说明

智能合约风险

合约不可升级。一旦部署，任何漏洞都无法修补。请只投入你能承受损失的资金。

价格与清算风险

hacds 价格完全由 AMM 池子决定。池子较浅时，大额交易会产生显著滑点。抵押借贷在价格下跌 20% 后可能被清算。

流动性风险

极端行情下，AMM 池子可能被单向抽干，导致兑换失败或撤池受限。

评分算法风险

HACD 评分基于主观维度（形状、颜色、命名）的量化规则。若评分标准与市场共识偏离，会影响 hacds 的内在价值支撑。
