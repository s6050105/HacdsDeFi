# HacdsDeFi 用户操作手册（操作 ↔ 工具 ↔ 命令）

> 合约：`VKNwXFFMCEn9XfMrhyHhd5rHqBnEyM3m1` ｜ hacds serial = `2000`
> 工具：`hacds_txbuild`（构建+签名）、`redeem.py`（HACD→积分一键）、`hacds_oracle.py`（预言机）、`curl`（只读查询）

## 0. 三类操作与工具归属

| 类型 | 说明 | 用什么 |
|---|---|---|
| **A. 函数调用** | 调合约的 `external` 函数 | `hacds_txbuild call` |
| **B. 转账触发钩子** | 把资产转入/转出合约，触发 `Payable*`/`Permit*` | `hacds_txbuild transfer` / `hacd` / `redeem.py` |
| **C. 只读查询** | 读状态，不发交易、不花 gas | 节点 `GET /query/contract/sandboxcall` |

---

## A. 函数调用（`call` 模式）

通用形式：
```
hacds_txbuild call <你> <ts> <合约> <函数名> "<值:类型,...>"
```
- `ts`：unix 秒，给 `0` 会用当前时间
- 参数格式是 **`值:类型`**（不是"类型:值"），如 `1000:u128`、`1H3s...:address`
- 环境变量：`HACDS_SIGN_KEY=<私钥文件>` 构建即签；`HACDS_FEE`（默认 0.0002 HAC）

| 操作 | 函数 | 参数示例 |
|---|---|---|
| HAC→hacds 兑换 | `swap_hac_to_ds` | `"1000000:u128,0:u128"` （hac_in, min_out） |
| hacds→HAC 兑换 | `swap_ds_to_hac` | `"1000000:u128,0:u128"` |
| 加流动性 | `add_liquidity` | `"500000:u128,500000:u128"` |
| 撤流动性 | `remove_liquidity` | `"100000:u128"` |
| 收 LP 奖励 | `lp_harvest` | `-`（无参） |
| 追加抵押 | `loan_add_collateral` | `"100000:u128"` |
| 借 HAC | `loan_borrow` | `"50000:u128"` |
| 还款 | `loan_repay` | `"50000:u128"` |
| 清算 | `loan_liquidate` | `"<借款人地址>:address"` |
| 管理：改费率 | `set_fee` | `"50:u128"`（万分比） |
| 管理：换预言机 | `set_oracle` | `"1H3s...:address"` |
| 管理：暂停 | `set_paused` | `"1:u8"` |
| 管理：续租 | `rent_batch` | `"0x<键>:bytes,21:u128,300:u128"` |

## B. 转账触发钩子（`transfer` / `hacd` / `redeem.py`）

通用形式：`hacds_txbuild transfer <main> <ts> <子形态> ...`

| 子形态 | 动作 | 用途 | 命令 |
|---|---|---|---|
| `hac-to` | `TransferHacTo`(1) | 充 HAC → 得 `bal:hac` 积分 | `transfer <你> 0 hac-to <合约> <金额>` |
| `hac-from` | `TransferHacFrom`(13) | 从某人 HAC → 你 | `transfer <你> 0 hac-from <地址> <金额>` |
| `hac-from-to` | `TransferHacFromTo`(14) | **合约 → 你**（提 HAC 积分） | `transfer <你> 0 hac-from-to <合约> <你> <金额>` |
| `asset-to` | `TransferAssetTo`(17) | **hacds 入合约**（反向兑换前置） | `transfer <你> 0 asset-to <合约> hacds <atoms>` |
| `asset-from` | `TransferAssetFrom`(18) | 从某人 hacds → 你 | `transfer <你> 0 asset-from <地址> hacds <atoms>` |
| `asset-from-to` | `TransferAssetFromTo`(19) | **合约 → 你**（领取 hacds 实物） | `transfer <你> 0 asset-from-to <合约> <你> hacds <atoms>` |

> `hacds` 是 serial 2000 的别名，也可直接写 `2000`。
> 金额写法：HAC 用 `1:248`（1 HAC）或 `0.5`（小数走 MEI）；**不要写 `0.5:248`**（非法）。

### HACD 存入（得 hacds 积分）——用 `redeem.py` 或 `hacd` 模式
```
# 一键（自动查钻石→取证书→拼交易→签名）
python redeem.py --names MVUUBA,HYXYHY --key <私钥> --contract <合约> --out signed.txt

# 或手工：先从预言机取证书拼成 hex 文件，再
hacds_txbuild hacd <你> 0 <合约> MVUUBA,HYXYHY <cert.hex>
```

### HACD 赎回（合约 → 你）——`hacd` 模式同线，方向在 PermitHACD 侧
需携带证书（合约要重算评分），动作形态与存入相同（`TransferHacdTo` 从合约视角转出）。

## C. 只读查询（不发交易）

```
curl "http://127.0.0.1:8082/query/contract/sandboxcall?contract=<合约>&function=<函数>&caller=<你>&params=<值:类型,...>"
```

| 查什么 | 函数 |
|---|---|
| HAC 积分 | `balance_hac` `<地址>:address` |
| hacds 账目 | `balance_ds` `<地址>:address` |
| 池价 | `pool_price` |
| 池储备 | `amm_reserves` / `amm_reserve_ds` |
| 借贷状态 | `loan_status` `<地址>:address` |
| 债务/抵押 | `loan_debt_of` / `loan_coll_of` |
| LP 份额 | `lp_share_of` `<地址>:address` |
| 待领 HAC/DS | `lp_pending_hac` / `lp_pending_ds` |
| 金库待结算 | `treasury_pending` `<kind>:u128` |
| 评分预览 | `quote_score` `<name>:bytes,<vg>:bytes,<num>:u128` |

> `caller` 必须是**有 HAC 的地址**，否则会因余额不足失败（这是沙箱的 gas 预扣要求）。
> 纯查询不需要签名、不消耗真实 gas。

## D. 一个完整的用户闭环

```
① 充 HAC          transfer ... hac-to     合约 10       → bal:hac += 10
② 换 hacds        call swap_hac_to_ds     1000000,0     → due += 出腿
③ 领 hacds 实物   transfer ... asset-from-to 合约 你 hacds <n>   → 链上资产到手
④ 赎回 HACD       hacd 合约... 带证书                      → PermitHACD
⑤ 提 HAC          transfer ... hac-from-to 合约 你 5      → bal:hac → 链上 HAC
```

每笔交易生成后，用节点核对无误再广播：
```
curl -X POST "http://127.0.0.1:8082/util/transaction/check?hexbody=true" --data-binary @signed.txt
curl -X POST "http://127.0.0.1:8082/submit/transaction?hexbody=true" --data-binary @signed.txt
```

## E. 实测核验（2026-10-20）

`hacds_txbuild transfer` 六个子形态全部经节点 `/util/transaction/check` 解析确认：

| 子形态 | 解析出的动作 |
|---|---|
| hac-to | kind 1，to=合约 |
| hac-from | kind 13，from=地址 |
| hac-from-to | kind 14，from/to 正确 |
| asset-to | kind 17，serial 2000 |
| asset-from | kind 18，serial 2000 |
| asset-from-to | kind 19，serial 2000 |

`hacds` 别名正确映射到 serial=2000；签名 `verify_signature` 全部通过。
