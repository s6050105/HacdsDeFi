# hacds 交易构建服务 · 部署说明

> 对应审计项 **M-8**：官网 `/api/build` 后端此前不存在，导致官网控制台的
> 所有写操作（swap / 加池 / 撤池 / 借还）必然失败。

---

## 1. 这是个什么服务

官网是纯静态站，浏览器里**不重新实现**合约调用编码——那样等于给链上行为
造第二份实现，一旦与合约不一致，用户签的就是错交易，而且现场无法调试。

所以官网把写操作交给后端：

```
浏览器  --POST /api/build-->  Cloudflare Worker  --反代-->  hacds_build_server
                                                              |
                                                              v
                                                    hacds_txbuild（Rust 引擎）
                                                              |
         <--{ txbody, fee }-----------------------------------+
         |
         v
   MoneyNex 插件钱包签名 → 广播
```

**本服务不签名、不广播、不持私钥。** 它只把合约调用参数编码成未签名交易体。
就算服务被完全攻破，攻击者也拿不到任何资金能力。

## 2. 服务器前置：编译 Rust 引擎

本服务复用 PC 钱包 / Android 共用的 `hacds_txbuild`，保证编码正确性由同一份
代码保证（不是 Python 重写一遍）。

```bash
# 1) 克隆 fullnode 源码（或上传已有的）
cd /opt
git clone <fullnode-repo> hacash_fullnode   # 或用 rsync 上传
cd hacash_fullnode

# 2) 编译（只需一次，约 3~5 分钟）
cargo build --release -p testkit --bin hacds_txbuild

# 3) 验证
./target/release/hacds_txbuild 2>&1 | head -3
```

## 3. 上传并启动服务

```bash
# 上传脚本
scp hacds_build_server.py root@<server>:/opt/hacds-build/

# 启动（先手动跑一次确认能起）
python3 /opt/hacds-build/hacds_build_server.py \
    --host 127.0.0.1 \
    --port 8125 \
    --contract T1A8kaeWqK6wMUw5UMHCA6tMQ1iBdECyH \
```

## 4. systemd 托管

`/etc/systemd/system/hacds-build.service`：

```ini
[Unit]
Description=HacdsDeFi tx build service (website /api/build)
After=network-online.target

[Service]
Type=simple
WorkingDirectory=/opt/hacds-build
ExecStart=/usr/bin/python3 /opt/hacds-build/hacds_build_server.py \
    --host 127.0.0.1 --port 8125 \
    --contract T1A8kaeWqK6wMUw5UMHCA6tMQ1iBdECyH \
    --txbuild /opt/hacash_fullnode/target/release/hacds_txbuild \
    --cors-origin https://hacds.com
Restart=always
RestartSec=10

# 本服务不需要任何特权，也从不接触私钥
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=strict
ProtectHome=true
ReadOnlyPaths=/opt/hacds-build /opt/hacash_fullnode/target/release/hacds_txbuild

StandardOutput=append:/var/log/hacds-build.log
StandardError=append:/var/log/hacds-build.log

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now hacds-build
sudo systemctl status hacds-build
```

> **注意**：服务默认只听 `127.0.0.1`。对外访问走 Cloudflare Worker 反代，
> 不要把 8125 直接暴露到公网。

## 5. 接上 Cloudflare Worker

Worker 的路由逻辑已经支持（`worker/index.js` 的 `route()`）：

```js
if (p === '/api/build') {
  if (!env.BUILD_ORIGIN) return { error: 'build_service_unconfigured' };
  return { origin: env.BUILD_ORIGIN, path: '/api/build' };
}
```

配置环境变量：

```bash
cd hacds.com/worker
wrangler secret put BUILD_ORIGIN
# 输入：https://build.hacds.com   （或内网穿透地址）
```

⚠ 如果服务器只监听 `127.0.0.1`，Worker 从公网访问不到。两种做法：

| 做法 | 说明 |
|---|---|
| **A. 加 nginx 反代 + TLS** | `build.hacds.com` → `127.0.0.1:8125`，推荐 |
| B. 服务直接听 `0.0.0.0` | 需自行加防火墙 + IP 白名单，不推荐 |

nginx 配置片段：

```nginx
server {
    listen 443 ssl http2;
    server_name build.hacds.com;
    # ssl_certificate ... （略）

    location / {
        proxy_pass http://127.0.0.1:8125;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header Origin $http_origin;
    }
}
```

## 6. 安全边界

| 边界 | 实现 |
|---|---|
| **不持私钥** | 服务全部代码里没有私钥读取、没有签名调用 |
| **不广播** | 只产出 `txbody`，广播由用户钱包完成 |
| **函数白名单** | `ALLOWED_FNS` 只含 11 个合约真实存在的写函数 |
| **参数校验** | 长度 ≤1024、项数 ≤16、字符集 `[0-9A-Za-z:,._-]` |
| **地址校验** | base58 字符集 + 长度 26–36 |
| **限流** | 单 IP 30 次/分钟 |
| **CORS** | 只允许 `--cors-origin` 列出的来源 |
| **不回显内部路径** | 构建失败只返回首行摘要（≤200 字符） |

### 白名单核对

```bash
python3 - <<'EOF'
import re, sys
sys.path.insert(0, '/opt/hacds-build')
from hacds_build_server import ALLOWED_FNS
src = open('/opt/hacds-build/HacdsDeFi3000.fitsh', encoding='utf-8').read()
ext = set(re.findall(r'function external (\w+)', src))
bad = [f for f in ALLOWED_FNS if f not in ext]
print('白名单无效项:', bad or '无')
EOF
```

## 7. 排障

| 现象 | 原因 | 处理 |
|---|---|---|
| `/health` 通但 `/api/build` 报 `engine_missing` | `--txbuild` 路径不对 | 检查 `ls -l` 该路径 |
| 报 `fn_not_allowed` | 前端传了白名单外的函数 | 核对 `ALLOWED_FNS` |
| 报 `build_failed: invalid address` | 工程上 main/contract 地址格式错 | 检查合约地址是否为 `T1A8...` |
| Worker 报 `build_service_unconfigured` | 没配 `BUILD_ORIGIN` | `wrangler secret put BUILD_ORIGIN` |
| Worker 报 `upstream_failed` | 服务器不通 / TLS 问题 | 从本机 `curl` 试 `https://build.hacds.com/health` |

## 8. 与官网的接口约定

**请求**

```json
{
  "fn": "swap_hac_to_ds",
  "params": "100000000:u128,0:u128,1792469415:u128",
  "main": "1H3sFZ53HzNVUVN97mjpC9JT8s2PqKMyRu",
  "fee": null,
  "gasMax": 99
}
```

**成功**

```json
{
  "txbody": "03006ade3a2716...6300",
  "fee": "0.0002 HAC",
  "fn": "swap_hac_to_ds",
  "contract": "T1A8kaeWqK6wMUw5UMHCA6tMQ1iBdECyH"
}
```

**失败**

```json
{ "error": "fn_not_allowed" }
{ "error": "build_failed", "detail": "invalid address" }
```

前端 `txbuild.js` 会把错误码翻译成中文再抛给 UI。
