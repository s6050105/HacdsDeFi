# HACDS 预言机 · 服务器部署说明

> 目标服务器：43.251.101.101（已运行 Hacash 全节点）
> 预言机脚本：`hacds_oracle.py`（单文件，零第三方依赖，Python 3）

## 0. 结论先行：预言机不需要 gas，也不需要 HAC

预言机是**只读签名者**，不发起任何交易：

- 它只做两件事：① 从全节点 RPC **读**钻石基因；② 用预言机私钥对 29B 证书**签名**后返回。
- 证书最终由**用户自己的 `PayableHACD` 交易**携带（放进该交易的 `Message` 字段），
  由合约的 `verify_cert` 用 `verify_signature(digest, cfg:oracle, sign)` 验证。
- 因此 **gas / 手续费由发起那笔交易的用户支付**，预言机账户无需余额、无需 gas。
  （预言机地址可以一直是 0 HAC，链上验证只看签名是否由 `cfg:oracle` 对应的私钥签出。）

代码佐证：`hacds_oracle.py` 中**没有任何**提交交易（`/submit`）的调用，
只有 `fetch_diamond()` 的 GET 读取与本地 `sign_digest()`。

## 1. 服务器前置

- Python 3（脚本仅用标准库：hashlib / hmac / json / struct / urllib / http.server）
- 一个可访问的全节点 RPC（本机 `http://127.0.0.1:<RPC端口>`；端口见节点配置）

> 注意：脚本默认 `--node http://127.0.0.1:3338`。若你的节点 API 用的是其它端口
> （例如本机开发环境用 8082），启动时显式传 `--node`。

## 2. 放置文件

```bash
sudo mkdir -p /opt/hacds-oracle
# 上传 hacds_oracle.py 到该目录（从开发机 scp，或直接粘贴）
sudo cp hacds_oracle.py /opt/hacds-oracle/
sudo chmod 755 /opt/hacds-oracle/hacds_oracle.py
```

## 3. 放置预言机私钥（关键：0600）

把预言机私钥（64 hex，**无 0x**，内容应与 `1H3sFZ53HzNVUVN97mjpC9JT8s2PqKMyRu` 对应）
写到服务器，并收紧权限到仅属主可读：

```bash
sudo mkdir -p /opt/hacds-oracle/keys
# 方式 A：直接写入（回显，仅建议在无他人可见的终端）
printf '%s\n' '<64位hex私钥>' | sudo tee /opt/hacds-oracle/keys/oracle.key >/dev/null
# 方式 B（更安全）：scp 已生成好的文件上去
#   本地: scp <keyfile> user@host:/tmp/oracle.key
#   服务器: sudo mv /tmp/oracle.key /opt/hacds-oracle/keys/oracle.key

sudo chown root:root /opt/hacds-oracle/keys/oracle.key
sudo chmod 600 /opt/hacds-oracle/keys/oracle.key
```

## 4. 先做离线自检 + 出证验证

```bash
cd /opt/hacds-oracle
python3 hacds_oracle.py selftest          # 应输出 SELFTEST PASSED

# 用真私钥对一笔钻石出证，并校验密钥地址与链上 cfg:oracle 一致
python3 hacds_oracle.py cert --name MVUUBA \
  --node http://127.0.0.1:<RPC端口> \
  --key-file keys/oracle.key \
  --expect-address 1H3sFZ53HzNVUVN97mjpC9JT8s2PqKMyRu
# 成功则输出 name/number/visual_gene/score/cert_message_hex/sign_hex 等
```

`--expect-address` 是安全闸：若密钥与链上已固化的预言机地址不符，脚本直接报错退出。

## 5. 以服务方式常驻

### 5.1 systemd（推荐）

`/etc/systemd/system/hacds-oracle.service`：

```ini
[Unit]
Description=HACDS gene-certificate oracle
After=network.target

[Service]
Type=simple
User=hacds
WorkingDirectory=/opt/hacds-oracle
# 只读节点；如节点在别的主机，改成对应 http://host:port
Environment=HACDS_ORACLE_KEY_FILE=/opt/hacds-oracle/keys/oracle.key
ExecStart=/usr/bin/python3 /opt/hacds-oracle/hacds_oracle.py serve \
  --port 8123 --node http://127.0.0.1:3338 \
  --key-file /opt/hacds-oracle/keys/oracle.key \
  --expect-address 1H3sFZ53HzNVUVN97mjpC9JT8s2PqKMyRu
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

```bash
sudo useradd -r -s /usr/sbin/nologin hacds || true
sudo chown -R hacds: /opt/hacds-oracle
sudo systemctl daemon-reload
sudo systemctl enable --now hacds-oracle
systemctl status hacds-oracle --no-pager
```

### 5.2 直接后台跑（临时）

```bash
cd /opt/hacds-oracle
nohup python3 hacds_oracle.py serve --port 8123 \
  --node http://127.0.0.1:3338 \
  --key-file keys/oracle.key \
  --expect-address 1H3sFZ53HzNVUVN97mjpC9JT8s2PqKMyRu \
  > oracle.log 2>&1 &
```

## 6. 验证与服务接口

```bash
curl http://127.0.0.1:8123/health
# -> {"ok": true, "oracle": "1H3sFZ53HzNVUVN97mjpC9JT8s2PqKMyRu"}

curl "http://127.0.0.1:8123/cert?name=MVUUBA"
# -> 证书 JSON（含 cert_message_hex / sign_hex / score / oracle_address）
```

- `GET /health` → 存活 + 预言机地址
- `GET /cert?name=<6位钻石名>` → 该钻石的证书

## 7. 安全清单

- [ ] 私钥文件 `chmod 600`、属主为运行用户；文件内容不含 `0x` 前缀
- [ ] 用 `--expect-address` 锁定链上预言机地址，防装错密钥
- [ ] 不要把私钥写进命令行参数、日志或 systemd 的 `ExecStart`（用文件注入）
- [ ] 对外暴露 8123 时加防火墙白名单 / 反向代理鉴权（默认只绑 `0.0.0.0`，无鉴权）
- [ ] 定期核对 `cfg:oracle` 未被 `set_oracle` 更改
