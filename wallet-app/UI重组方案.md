# 钱包 UI 重组方案

> 定稿：2026-11-11
> 状态：**方案已确认，等待实施**
> 背景：#3000 删除了预言机与管理员，现有界面仍保留这些入口，且功能分类混乱

---

## 一、核心分类原则

按「**对手方是谁**」划分，而不是按技术实现：

| 类别 | 定义 | 归处 |
|---|---|---|
| **转账** | 链上地址 ↔ 链上地址，**不碰合约** | 转账页 |
| **资金** | 我的地址 ↔ **合约地址**，只做充提 | 资金页 |
| **业务** | 与合约的具体业务交互 | 兑换 / 流动性 / 借贷 / HACD |

**关键约束**：转账页里不允许出现任何合约地址作为对手方。

---

## 二、最终结构：7 个一级页签

```
兑换 | 流动性 | 借贷 | HACD | 转账 | 资金 | 工具
```

---

### 1. 兑换 `swap`

| 操作 | 合约函数 |
|---|---|
| HAC → hacds | `swap_hac_to_ds` |
| hacds → HAC | `swap_ds_to_hac` |

页内显示：池价、滑点预估、兑换比例。

> **依赖提示**：兑换用的是合约内积分，不是钱包里的链上资产。
> 兑换页需提供一个「去资金页充值」的跳转链接。

---

### 2. 流动性 `lp`

| 操作 | 合约函数 |
|---|---|
| 加池 | `add_liquidity` |
| 撤池 | `remove_liquidity` |
| 领 LP 奖励 | `lp_harvest` |

页内显示：我的 LP 份额、待领 HAC / hacds、池子两侧储备。

> 领奖励原在 `amm` 和 `liq` 两处，**合并为一处**。

---

### 3. 借贷 `loan`

| 操作 | 合约函数 |
|---|---|
| 加抵押 | `loan_add_collateral` |
| 借款 | `loan_borrow` |
| 还款 | `loan_repay` |
| 清算 | `loan_liquidate` |

页内显示：健康度、债务、抵押率、可借上限。

> 原样保留，这是现有分类中最合理的一页，无需调整。

---

### 4. HACD `hacd`

| 功能 | 与合约交互 |
|---|---|
| 浏览 / 筛选 / 排序 | ✗ 纯本地 |
| 详情（基因、分数、编号、持有者） | ✗ 纯本地 |
| **批量存入**（铸出 hacds） | ✓ `PayableHACD` |
| **批量赎回** | ✓ `PermitHACD` |
| **赎回（指定收款地址）** | ✓ `PermitHACD` |
| **复制选中名字** | ✗ 纯本地，逗号分隔 |

**「复制名字」的既定用法**（已实现，`app.js:1923`）：

1. 在 HACD 页勾选多颗钻石
2. 点「复制名字」→ 剪贴板得到 `WTYUIA,HYXYHY,UETWNK`
3. 切到转账页，粘贴到 HACD 转账的名称输入框

> HACD 存入/赎回原分散在 `trade` 与 `hacd` 两页，**合并到本页**。

---

### 5. 转账 `xfer` —— 只做链上地址之间

| 操作 | 方向 | 来源 |
|---|---|---|
| HAC 转账 | 我 → 他人 | 原 `xfer` |
| hacds 转账 | 我 → 他人 | 原 `xfer` |
| HACD 转账 | 我 → 他人 | 原 `xfer` |
| 其它资产转账 | 我 → 他人 | 原 `xfer` |

**HACD 转账支持粘贴逗号列表**，与 HACD 页的复制功能配合。

**移出本页的**：金库清扫 ×2（运维动作，移到工具页）。

---

### 6. 资金 `fund`（新增）

**唯一与合约进行资产充提的入口**：

| 操作 | 方向 | 合约钩子 |
|---|---|---|
| 存入 HAC | 我 → 合约 | `PayableHAC` |
| 提取 HAC | 合约 → 我 | `PermitHAC` |
| 存入 hacds | 我 → 合约 | `PayableAsset` |
| 领取 hacds | 合约 → 我 | `PermitAsset` |

页内显示：合约内的 HAC 积分（`balance_hac`）、hacds 配额（`balance_ds`）。

**必须包含的说明区块**：

> 📌 **HACD 资产不进这里**
>
> 本页只处理 HAC 与 hacds 两种资产与合约的充提。
> 钻石（HACD）的存入与赎回请到 **HACD 页** 操作。
> [→ 前往 HACD 页]

---

### 7. 工具 `tools`

页内分三组：

| 分组 | 功能 | 来源 |
|---|---|---|
| **查询** | 11 个只读查询 | 原 `query` |
| **运维** | 金库清扫（HAC）、金库清扫（hacds）、清算监控与借款人名单 | 原 `xfer` + 原 `liq` |
| **高级** | 原子交易、离线签名 | 原 `combo` + 原 `offline` |
