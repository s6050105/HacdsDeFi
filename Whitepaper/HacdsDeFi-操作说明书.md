# HacdsDeFi 操作说明书

2026-10-21　适用钱包版本 0.1.0（Windows 64 位）

## 这份说明书是给谁看的

给拿到这个钱包、第一次打开、不知道该点哪里的人。

假设你不懂合约、不懂 HVM，也不需要懂。看完你应该能自己完成：装好、建钱包、把钻石换成 hacds、在池子里换币、抵押借币、把币转给别人。

涉及金额的地方都会写清楚单位。**这是最容易出错的地方，请务必看第 9 节。**

---

## 1. 先准备三样东西

**一台 Windows 电脑**（64 位）。钱包是桌面程序，没有网页版、没有手机版（安卓版在做）。

**装好后的两个文件**：`HacdsDeFi-Setup-0.1.0-x64.exe` 是安装版，双击装好即可；`HacdsDeFi-0.1.0-x64.exe` 是免安装版，双击直接运行。任选一个。

**能连上服务器**。钱包本身不存链上数据，它要连三个服务：

| 服务 | 地址 | 干什么 |
|---|---|---|
| 节点 | `43.251.101.101:8082` | 查余额、广播交易 |
| 预言机 | `43.251.101.101:8123` | 给钻石出评分证书（兑换 hacds 要用） |
| 索引器 | `43.251.101.101:8124` | 借贷清算用的台账（可选） |

这三个地址已经填好了。只要网络通，不用改。如果换了服务器，在顶部改。

## 2. 第一次打开

打开后顶部是这样一排：

```
[节点] [预言机] [合约] [索引器] [保存] [检测]     [−] 100% [+] [⟲]   [语言▾]
```

**第一件事：点「检测」。**

点完看下方日志区，应该出现两行：

- `节点 OK，高度 79xxxx`
- `预言机 OK，1H3sFZ53…`

两条都 OK 就说明网络通了，可以往下走。如果报错，看第 10 节。

右边那个 `100%` 是界面缩放，字小可以点 `+`。最右边的下拉框是语言（简体中文 / English / Türkçe）。

## 3. 建钱包（或导入已有的）

这时中间是「钱包未解锁」，下面一排按钮：

```
钱包未解锁   [创建钱包] [导入钱包] [打开钱包文件…] [钱包管理] [用外部私钥文件]
```

### 3.1 新用户：创建钱包

点「创建钱包」，填两样：

- **密码**：给它设一个。这个密码保护你的钱包文件，丢了就解不开。
- **备注**（可选）：比如「主钱包」。

确定后，钱包就建好了，地址会显示在顶部。

### 3.2 已有钱包：三种导入方式

| 情况 | 点哪个 |
|---|---|
| 手里有 64 位私钥（一串十六进制） | 「导入钱包」 |
| 手里有以前存的 keystore 文件 | 「打开钱包文件…」 |
| 私钥存成一个文件，不想导入 | 「用外部私钥文件」 |

导入后同样会出现在账户区。

### 3.3 管多个钱包

点「钱包管理」，能看到所有钱包的地址、备注、余额。可以打开、重命名、删除。

**切钱包有个快捷方式**：直接点顶部那个绿色地址，会弹出列表，选一个切过去（要输密码）。不用先进「钱包管理」。

## 4. 解锁后看到什么

解锁后顶部变成：

```
🔓 1You…Addr   [管理员]   [刷新资产] [导出私钥] [锁定 / 退出]
```

**「刷新资产」**：链上数据不会自己更新，想知道最新余额就点它。

**「锁定 / 退出」**：用完记得点。锁定后私钥从内存里清掉，别人拿到电脑也动不了你的钱。

下面一排页签，是你所有能做的事：

```
兑换 / 存取 | AMM 与流动性 | 借贷 | 链上转账 | HACD 收藏 | 只读查询
清算 / 结算 | 原子交易 | 离线签名
```

「管理员」页签只有合约管理员才看得到，普通用户没有这一项，不用管。

## 5. 首屏三张卡怎么读

解锁后最上面有三张卡。**看懂这三张，剩下的都好办。**

### 5.1 资产总览

| 显示 | 意思 |
|---|---|
| **HAC** | 你链上有多少 HAC |
| **HACD 钻石** | 你手上有多少颗钻石 |
| **预期 hacds** | 这些钻石如果拿去兑换，大概能换多少 hacds |
| **待领取 hacds** | 钻石已经存进合约了，合约欠你的 hacds（记账值） |
| **已持有 hacds** | 已经领到手、可以自由转账的 hacds |
| **合约内 HAC 积分** | 你充进合约的 HAC（换币和借贷都用这个账） |

关于 hacds，记住这条线就行：

```
手上有钻石  →(存入兑换)→  合约欠你（待领取）  →(领取)→  真正到手的 hacds
```

**「预期」和「已持有」是两回事**，别混。前者是估算，后者是能花的钱。

### 5.2 协议状态

池子里有多少钱、你占多少份额、你的借贷情况。日常主要是看这几个：

- **池 HAC / 池 hacds**：池子的规模，决定换币价格
- **池价**：现在是 1 个 hacds 值多少 HAC
- **我的 LP / 我的债务 / 我的抵押**：你自己的

### 5.3 借贷状态

**这张卡是专门让你少试错的。** 它一直显示：

- 你的债务、抵押、抵押能值多少 HAC
- **我的可借上限** —— 你现在还能借多少
- 清算状态：安全 / 可清算 / 无债务

**借钱之前先看这张卡**，就不用靠一次次失败去试了。

## 6. 每笔交易都是同一套动作

不管你在哪个页面做什么操作，流程都一样，五步：

```
填参数  →  [生成交易]  →  预览区出现  →  [校验]  →  [广播]
```

**① 生成交易**：本地签名，这一步还不花手续费，也不上链。

**② 预览区**：出现一栏信息，几个按钮：

| 按钮 | 作用 |
|---|---|
| **复制 hex** | 复制交易原文 |
| **保存…** | 存成文件 |
| **校验** | 让节点检查这笔交易格式对不对（需要联网） |
| **翻译** | 让节点用人话说明这笔交易要干什么 |
| **广播** | 真正发出去 |

**③ 强烈建议先点「翻译」看一眼。** 它会用人话列出这笔交易做什么，比如「Transfer 1 HAC from … to …」。确认没问题再广播。

**④ 广播**后日志会显示成功和交易号。

**⑤ 等出块。** Hacash 大约 **5 分钟**出一个块。广播成功只是进了待打包队列，**要等下一个块才真正生效**。所以点「刷新资产」发现数字没变是正常的，钱包会自动在 15、45、90、180、320 秒后帮你补刷。

## 7. 常见操作怎么做

### 7.1 把钻石换成 hacds（最常用）

去 **「兑换 / 存取」** 页，找到 **「HACD → hacds（存入兑换）」**。

1. 在「钻石名（逗号分隔）」里填钻石名字，多个用逗号隔开，比如 `MVUUBA,HYXYHY`
2. 点「生成交易」→「翻译」看一眼 →「广播」

**⚠ 一笔最多填一颗钻石。**

这不是软件限制，是链上的硬限制。每颗钻石链上验签要重算一次评分，大约吃掉 3,000 单位的计算资源，而一笔交易的资源上限是 6,100。两颗就是 6,101，超一点点，直接失败。

**想一次存多颗怎么办**：去 **「HACD 收藏」** 页勾选多颗，点「批量存入兑换」——钱包会自动拆成每笔一颗、逐笔广播。

存进去以后，hacds 记在「待领取 hacds」里，还没到你手上。

### 7.2 把 hacds 领到手

还在 **「兑换 / 存取」** 页，找到 **「领取 hacds 实物（合约 → 我）」**。

填数量（**单位是 atoms**，见第 9 节），生成、翻译、广播。

领完，「已持有 hacds」会增加。这时候的 hacds 才是能自由转账的资产。

### 7.3 充 HAC 进合约 / 提出来

- **「充 HAC（HAC → 合约，得积分）」**：把钱包里的 HAC 转进合约，合约记成「HAC 积分」。**AMM 换币和借贷都用这个积分**，所以要玩这两个功能得先充。
- **「提 HAC（合约 → 我）」**：把积分提回链上的 HAC。

填金额时**单位是 HAC**，直接填 `10` 就是 10 个 HAC。

### 7.4 在池子里换币（AMM）

去 **「AMM 与流动性」** 页。

**HAC → hacds**：
- 填「投入 HAC 积分（HAC）」和「最少得到（atoms，0=不限）」
- 填完下方立刻显示预期能换到多少，以及当前池价、费率
- 觉得合适就生成、广播

**hacds → HAC**：同理，填投入的 hacds（atoms）和最少得到（HAC）。

**「最少得到」是滑点保护。** 填 0 表示不限制。如果换币过程中价格变动太大导致实际到手低于你填的数，交易会自动失败（不会亏）。**建议填一个能接受的底线，而不是 0。**

### 7.5 加流动性赚手续费

去 **「AMM 与流动性」** 页，找到 **「加流动性」**。

加流动性就是往池子里同时放 HAC 和 hacds 两样东西，换回 LP 份额，之后靠份额分手续费。

**操作很简单：只用填一侧，另一侧钱包会自动帮你算好。**

- 你在「HAC 侧（HAC）」填个数，hacds 那边会立刻自动填上对应数量
- 反过来填 hacds 也同理

**为什么要自动算**：合约规定，两样东西的比例必须和池子里一致。比例对不上的话，多放的那一侧**不会给你任何份额，直接白送进池子**。所以钱包强制帮你对齐。

加完之后，下方会显示「预计获得 LP 份额 X」。如果两边比例不对（比如你手动改过），会出现红字提醒，并告诉你应该是多少。

**池子里 HAC 和 hacds 都没有时**（首笔注入）是例外：这时没有比例可对齐，两边都你自己定，份额按 `√(HAC × hacds)` 算。

**撤流动性**：填要销毁的 LP 份额，两样东西按比例一起退给你。

**领取 LP 奖励**：点「领取 LP 奖励」把攒下的手续费收进余额。不点也不会丢。

### 7.6 抵押借币

去 **「借贷」** 页。**顺序很重要：先抵押，再借钱。**

**① 追加抵押**

在「追加抵押」卡里填 hacds 数量（**单位 atoms**）。

下方会实时告诉你：这笔抵押值多少 HAC、追加后总共能借多少。

**② 借出 HAC**

在「借出 HAC」卡里填要借多少（**单位 HAC**）。

下方实时提示：
- 你当前的可借上限
- 这笔借款需要多少抵押（`≥ X atoms`）
- 够不够（✔ 或 ✘）

**如果 ✘ 还硬提交，会失败报错。** 这就是为什么先看提示。

**③ 还款**

在「还款」卡填金额，同时把 HAC 积分准备好。还清后抵押自动解锁。

**关于利息**：利率是年化 5%，但界面不单独显示你欠了多少利息——合约把利息算在一起了。**还款时链上会结算，按钱包提示的金额还就行。**

**关于清算**：抵押的东西价值如果跌得太多（抵押率跌破 200%），任何人都可以来清算你的仓位，你的抵押会被拿走并给清算人一笔奖励。**盯紧首屏那张「借贷状态」卡的清算状态**，显示「安全」就没事。

### 7.7 把币转给别人

去 **「链上转账」** 页。

| 想转什么 | 用哪一项 |
|---|---|
| HAC | 「HAC 转账」——金额写成 `1:248` 这种格式表示 1 个 HAC |
| hacds | 「hacds 转他人」——数量填 **atoms** |
| hacds 转回合约 | 「hacds 转入合约」 |
| **HACD 钻石** | **「HACD 转他人」——填钻石名和对方地址** |
| 其它资产（如 CARAT、HACP） | 「其它资产转账」——填 serial、地址、数量 |

**HACD 转他人**（把钻石送给别人）：填钻石名（逗号分隔，如 `KWTVSH,VHUSMI`）和目标地址。

- **一笔最多 200 颗**，不像「存入兑换」那样只能一颗一颗来 —— 因为点对点转账不经过合约，没有那个计算量限制
- 手续费框会自动按 `0.0002 HAC × 颗数` 预填。**想省一点就把它清空**，钱包会按节点费率自动算（颗数多时能省不少）
- 这一项**不碰合约**，纯粹把你的钻石转到对方地址，对方收到后就是他的了

**「其它资产转账」的 serial 填纯数字就行**，比如 `1111`。带上 `#` 也能识别，但不必要。

### 7.8 HACD 收藏页：看钻石、批量操作

**「HACD 收藏」** 页左边是所有钻石的缩略图，点一颗看右侧详情（图样、名称、编号、评分、五维明细、铭文）。

上面可以按形状、样式、最低分筛选。

**批量操作**：
- 按住 `Ctrl` 点卡片 = 加选一颗
- 按住 `Shift` 点 = 从上一颗连选到这个
- 选完点「批量存入兑换」或「批量赎回」
- 钱包会弹窗告诉你「将拆成 N 笔、每笔 1 颗」，确认后自动逐笔广播

还有个 **「复制名称」** 按钮，把选中的钻石名字按逗号拼好复制走，方便粘到别处。

## 8. 进阶功能（不看也能用）

### 8.1 只读查询

**「只读查询」** 页，一排按钮，点一下就去链上查个数，不发交易、不花手续费。查 HAC 积分、待领取 hacds、池价、池储备、你的债务抵押、LP 份额等等。

适合「我不想动钱，就想看看现在什么情况」。

### 8.2 原子交易

**「原子交易」** 页。可以把好几个操作合并成**一笔**交易：要么全成功，要么全失败，不会出现「做了一半」。

用法：在任何操作卡下面点 **「加入组合」**，把操作攒起来，最后到这一页点「构建原子交易」。

**注意：合并不能绕过「一笔一颗钻石」的限制。** 一笔交易共用同一份计算预算，存两颗照样超限。存钻石请用批量功能。

### 8.3 离线签名（冷热分离）

**「离线签名」** 页，给对安全要求高的用户。

思路是：**私钥永远不上网的机器**。

1. 在联网机上把操作填好，生成**未签名**的交易体，存成文件或记下那串文本
2. 拿到离网机（飞行模式、拔网线），在这一页粘贴、点「用当前钱包签名未签名体」
3. 把签名后的交易文本拿回联网机，点「广播已签名交易」

这样私钥所在的机器从头到尾没连过网。Hacash 的交易没有时效限制，离线签好放几天再广播也没问题。

**签名前建议先用「校验未签名体」和「翻译交易体」看一眼**，确认这笔交易就是你要的。

### 8.4 清算 / 结算

**「清算 / 结算」** 页三块：

1. **我的 LP 奖励**——一键结算
2. **金库清扫**——把累计的手续费转给金库
3. **借贷清算台**——列出所有能清算的仓位，谁都能来执行，有奖励

前两块跟普通用户有关。第三块是给专业用户的：**清算别人的仓位可以拿到奖励**，但要自己判断风险。

点「同步链上台账」会去索引器拉数据（不连索引器的话会本地扫块，慢很多）。

## 9. ⚠ 数字怎么看（最容易出错的一节）

**hacds 和 HAC 的单位完全不同，填错就是差一亿倍。**

### 9.1 hacds 用 atoms

hacds 的最小单位叫 **atoms**。钱包里**所有 hacds 的数字都是 atoms**，余额、池子、输入框，全都是。

```
1 个 hacds = 100,000,000 atoms
```

所以你在输入框里看到默认值 `100000000`，那就是 **1 个 hacds**。

**千万别把「个」填进去。** 比如你想转 70 个 hacds，不能填 `70`——那只是 70 atoms，不到一个 hacds 的百万分之一。要填 `7000000000`。

**怎么记**：输入框标签上写着 `（atoms）` 的，就是填 atoms。标签上写着 `（HAC）` 的，直接填 HAC 个数。

### 9.2 HAC 直接填个数

HAC 就简单，标签写「（HAC）」的地方，想充 10 个 HAC 就填 `10`。

**例外**：链上转账页的 HAC 金额要写成 `1:248` 这种格式（`1:248` = 1 个 HAC）。这是 Hacash 的金额写法，照输入框默认值的样式改就行。

### 9.3 对照表

| 你要操作 | 填什么单位 | 例子 |
|---|---|---|
| 加流动性 —— HAC 侧 | HAC | `1` |
| 加流动性 —— hacds 侧 | atoms | `33183372` |
| 换币 —— 投入 HAC | HAC | `1` |
| 换币 —— 投入 hacds | atoms | `100000000` |
| 追加抵押 | atoms | `100000000` |
| 借出 / 还款 | HAC | `0.5` |
| 转 hacds | atoms | `100000000` |
| 转其它资产 | atoms | `100000000` |

## 10. 出问题了怎么办

### 10.1 先看日志区

所有操作的结果、失败原因都打在底部日志区。**报错是中文的**，先说是什么问题，再给建议。

### 10.2 常见报错

| 你看到的 | 什么意思 | 怎么办 |
|---|---|---|
| **连不上节点/预言机** | 服务不可达 | 点「检测」看看；确认网络；确认顶部地址填对 |
| **地址为空或格式不对** | 地址没填全 | 重新完整复制一遍收款地址 |
| **地址校验位不对** | 地址复制时漏字符 | 重新复制 |
| **余额不足** | 该地址没有 HAC 付手续费/gas | 往这个地址充点 HAC |
| **resource gas 单桶上限超出** | 一笔存了多颗钻石 | 改成每笔一颗，或直接用「批量存入兑换」。**提高 gas 没用** |
| **超出可借上限** | 抵押不够就借钱 | 先去「追加抵押」 |
| **待领取 hacds 不足** | 想领的比合约欠你的多 | 看「待领取 hacds」，别超过它 |
| **兑换所需 hacds 不足，且自动补足失败** | 赎回钻石时配额不够，合约想用 HAC 帮你补但没成功 | 先充 HAC 或先兑换一些 hacds |
| **合约已暂停** | 管理员暂停了合约 | 等恢复，问运营方 |
| **状态已变化，请重试** | 期间链上变了 | 刷新后重做一次 |
| **请求超时 / 服务端错误** | 服务器慢或临时不可用 | 等一会儿重试，或换个节点 |

### 10.3 广播成功但余额没变

**正常。** 要等出块（约 5 分钟）。钱包会自动补刷几次，等着就行。

### 10.4 界面字太小 / 太大

顶部 `+` `−` 调，`⟲` 恢复 100%。

### 10.5 三张卡可以收起来

「资产总览」「协议状态」「借贷状态」标题左边的小三角点一下能折叠，腾出屏幕空间给下面的操作区。

## 11. 安全须知

**密码不要告诉任何人，也不要把「导出私钥」的结果给别人看。** 私钥 = 你的全部资产，谁拿到谁就能转走。

**「导出私钥」会明文显示私钥**，钱包会弹二次确认。导出后请离线手抄保存，别截图、别存网盘。

**用完点「锁定 / 退出」。**

**别在公共电脑上导入钱包。**

**链上交易不可撤销。** 广播之前一定点「翻译」看一眼收款的地址和金额对不对。转错了没人能帮你追回。

**看清地址再转。** 建议先从「复制」拿地址，别手打。

## 12. 一些术语的通俗解释

| 术语 | 通俗说 |
|---|---|
| **HAC** | 主链的原生币 |
| **HACD** | 钻石，有价值，可以换成 hacds |
| **hacds** | 钻石换来的资产，可以自由转账、交易、当抵押品 |
| **atoms** | hacds 的最小单位，1 hacds = 1 亿 atoms |
| **LP 份额** | 你放进池子的钱的凭证，靠它分手续费 |
| **池 / AMM** | 一个自动换币的资金池，价格由池子里两种币的数量决定 |
| **滑点保护** | 成交价不能比你设定的底线更差，否则自动取消 |
| **抵押率** | 你借的钱和你押的东西的比值，太低会被清算 |
| **清算** | 抵押不够时，别人可以强制卖掉你的抵押还债 |
| **gas** | 链上执行操作要消耗的计算资源，用 HAC 付 |
| **广播** | 把交易发到链上 |
| **出块** | 链上确认交易，大约每 5 分钟一次 |
| **冷钱包 / 离线签名** | 签名的机器不联网，私钥最安全 |
| **预言机** | 给钻石评分的服务，兑换 hacds 时要用到它签的证书 |
| **索引器** | 帮钱包统计「谁的借款该被清算」的后台服务 |

## 13. 一分钟速查（贴在旁边）

```
建钱包    → 创建钱包 → 设密码
查状态    → 点「刷新资产」
换 hacds  → 兑换/存取 → HACD→hacds → 一笔一颗
领 hacds  → 兑换/存取 → 领取 hacds 实物
充 HAC    → 兑换/存取 → 充 HAC（玩 AMM/借贷前必做）
换币      → AMM 与流动性 → 填一侧 → 看报价 → 广播
加池子    → AMM 与流动性 → 加流动性 → 只填一侧，另一侧自动
借钱      → 借贷 → 先「追加抵押」→ 再「借出 HAC」
转币      → 链上转账
每笔交易  → 生成交易 → 翻译 → 广播 → 等 5 分钟

单位：hacds 填 atoms（1 hacds = 100000000）
      HAC 直接填个数（10 就是 10 个）
```
